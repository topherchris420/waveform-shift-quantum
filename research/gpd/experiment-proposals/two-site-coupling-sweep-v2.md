# Proposal: two-site coupling sweep (protocol v2)

**Status:** executable as a *simulation*. **Not** executable as a laboratory experiment (see "What is missing").

## Question

Does the proposed scalar coupling create a population evolution distinguishable from the g = 0 baseline?

## Hypothesis

A spatially varying scalar contribution changes the predicted two-site trajectory.

## Design

| Element | Value |
| --- | --- |
| Baseline | g = 0: established two-site QM, same initial state, grid and propagator |
| Nulls | g = 0 sample; uniform static field; uniform driven field |
| Independent variables | g (swept), field contrast φ_B − φ_A, mixing Δ, drive amplitude a |
| Observables | P_B(t) (simulated observable); D(t), max D, mean D (numerical diagnostics) |
| Numerical requirements | norm ≤ 1e-10; controls ≤ 1e-12; ladder agreement ≤ 1e-3 at dt, dt/2, dt/4; observed order ≥ 1.5 or rounding level |
| Rejection criteria | Declared before execution and generated by `buildResearchQuestion` in `src/experiments/engine.ts` |

The card is bound into every v2 record and covered by its digest.

## Expected outcomes, derived beforehand

- **Driven preset:** a separation is present. Its size is set by g·(φ_B − φ_A) and the drive, relative to Δ.
- **Static preset:** a separation is present, but it is **exactly a detuning shift** (derivation §6). No static measurement could attribute it to g.
- **Null preset:** separation exactly 0 (derivation §2).

The observed results match: driven and static presets report `simulation_effect_present`, and the null preset reports `simulation_effect_absent`.

## What is missing before this could be a laboratory proposal

1. A physical identity for φ: which field, in what units, and how it is produced with a gradient between two sites.
2. A calibrated g, or at least a model-predicted scale for it.
3. A platform: a two-level or double-well system whose sites see different φ.
4. Independent calibration of E_B − E_A to better than g·Δφ. Otherwise the static effect is a detuning.
5. A plan that **varies φ in a controlled way**, since only modulation separates g from detuning. The driven protocol is the simulation analogue.
6. A resolution and noise model for P_B. Required sensitivity is `unknown`.
7. A decoherence model. The simulated evolution is closed.

Until 1–6 exist, the empirical falsification condition is defined but **not operational**.
